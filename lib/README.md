# lib

외부 라이브러리 사본입니다. 편집기가 `md.html(오프라인)` 파일을 만들 때 이 파일들을 받아 HTML 안에 넣습니다.
jsDelivr(`https://cdn.jsdelivr.net/gh/okpojung/markdown-editor@main/lib/...`)를 통해 CORS 허용 상태로 받기 위해 저장소에 둡니다.

| 파일 | 원본 | 라이선스 |
|---|---|---|
| toastui-editor-all.min.js | TOAST UI Editor 3.2.2 (https://uicdn.toast.com/editor/3.2.2/toastui-editor-all.min.js) | MIT, © NHN Cloud Corp. |
| toastui-ko-kr.min.js | TOAST UI Editor 3.2.2 i18n ko-KR | MIT, © NHN Cloud Corp. |

나머지 라이브러리(CodeMirror 5.65.16, Mermaid 11)는 jsDelivr npm 경로에서 직접 받습니다.
