설치하지 않아도 쓸 수 있나요?

네. 편집기 열기를 누르면 브라우저에서 바로 사용할 수 있습니다. HTML 다운로드를 선택하면 파일을 내려받아 브라우저로 열 수도 있습니다. 이 온라인 편집기는 라이브러리를 불러오기 위한 인터넷 연결이 필요합니다.

문서는 자동으로 저장되나요?

일반 모드에서는 문서 내용이 현재 브라우저의 localStorage에 자동 보관됩니다. 계정 기반의 클라우드 백업은 아닙니다. 브라우저 데이터 삭제나 사용 환경 변경으로 기록이 사라질 수 있으니, 중요한 문서는 .md 또는 .md.html 파일로 직접 저장하세요.

.md와 .md.html은 어떻게 다른가요?

.md는 마크다운 원문을 담는 텍스트 파일입니다. .md.html은 원문과 편집기를 함께 담아 브라우저에서 열고 편집할 수 있는 HTML 파일입니다. 온라인 저장은 열 때 인터넷이 필요하며, 오프라인 저장은 필요한 라이브러리까지 포함합니다.

인터넷이 없어도 사용할 수 있나요?

편집기에서 ‘md.html(오프라인)로 저장’을 선택해 만든 파일은 인터넷 없이 열고 편집할 수 있습니다. 오프라인 파일을 만드는 시점에는 라이브러리를 가져오기 위해 인터넷이 필요합니다. 문서에 넣은 외부 이미지 등은 별도로 연결이 필요할 수 있습니다. 이 페이지의 HTML 다운로드는 오프라인 묶음이 아닌 온라인 편집기입니다.

모든 브라우저에서 같은 파일에 저장되나요?

Chrome·Edge에서는 처음 저장할 때 파일 위치를 선택한 뒤 같은 파일에 바로 저장할 수 있습니다. 다른 브라우저에서는 새 파일로 내려받을 수 있습니다. 브라우저 설정과 지원 범위에 따라 저장 방식이 달라집니다.

무료인가요? 소스도 볼 수 있나요?

네. MIT 라이선스의 무료 오픈소스입니다. GitHub 저장소에서 소스와 사용 안내를 확인할 수 있습니다.
