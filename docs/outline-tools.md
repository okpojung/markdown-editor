# 아웃라인 도구와 분할 위치 동기화

## 편집 대상

아웃라인 단독 보기 또는 분할 왼쪽의 아웃라인 항목을 클릭한 뒤 제목·강조·목록·링크·코드·표 도구를 사용할 수 있습니다. 편집 중 문자를 선택하면 그 범위에, 항목만 선택하면 해당 항목에 적용합니다. 숨겨진 MD 커서는 대상이 아닙니다. 분할에서 오른쪽 렌더링을 클릭하면 도구는 계속 오른쪽에 적용됩니다.

빈 문서에서 글머리·번호·체크박스를 먼저 누르면 바로 입력할 수 있는 빈 항목이 생깁니다. 같은 도구를 다시 누르면 빈 표시를 취소합니다. 아웃라인의 Ctrl/Cmd+B·I·U·K와 기존 Ctrl+Z/Y를 사용할 수 있습니다.

표와 코드의 전용 대화상자는 기존처럼 사용할 수 있습니다. 대화상자를 연 뒤 외부 API로 문서를 교체하면 오래된 입력을 새 문서에 쓰지 않도록 닫습니다. 입력 중 저장하거나 보기를 바꾸면 미완료 아웃라인 입력부터 반영합니다. 제목·목록의 줄바꿈은 `<br>`로 보존합니다.

## 분할 보기

왼쪽 창에서 **아웃라인**을 고르면 아웃라인/렌더링 분할이 됩니다. 어느 쪽이든 스크롤하면 반대쪽이 해당 Markdown 블록과 블록 내부의 상대 위치를 따라갑니다. 항목 선택과 렌더링 커서 이동도 해당 위치를 드러냅니다.

- 반대쪽 커서·선택 범위는 옮기지 않습니다.
- 접힌 가지는 자동으로 펼치지 않습니다. 숨겨진 내용은 가장 가까운 보이는 상위 항목으로 대응합니다.
- 문서·언어·창 너비·접힘이 바뀌면 위치 지도를 다시 계산합니다.
- 맨 위·맨 아래를 함께 맞추고 프로그램에 의한 스크롤을 다시 따라가는 반복을 억제합니다.
- 분할이 아닌 보기에서는 반대쪽을 스크롤하지 않습니다.

아웃라인의 직접 문자 입력은 기존처럼 항목 입력 완료 시 Markdown에 반영됩니다. 저장·도구 적용·보기 전환에서도 먼저 반영합니다. 입력 중인 DOM을 스크롤 동기화 목적으로 강제로 저장하거나 반대쪽 포커스를 빼앗지 않습니다.

## 검증과 EMM 경계

`tests/outline.browser.js`는 자체 합성 문서 또는 설치 앱의 격리 smoke 문서에서만 실행합니다. 4언어·아웃라인/분할 편집, 선택 범위·줄바꿈·Undo/Redo·빈 목록·대화상자·접힘·긴 문단·양방향 스크롤·재생성·크기 변경·상위 항목 이동 등 270개를 검사합니다. `desktop/scripts/check-outline.cjs`가 정확한 목록을 설치 검증과 릴리스에 강제합니다.

공통 변경은 EMM 앱의 운영 반영을 뜻하지 않습니다. 담당자는 최신 EMM 코어 위에 선택적으로 통합하고 기존 인증·저장·충돌·발신자/출처 검사·ACK·보안 훅을 보존한 뒤 실제 서버에서 저장·재열기를 검증해야 합니다.
