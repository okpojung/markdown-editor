# 편집기 v6 변경 및 검증

## 변경
- 링크 팝업: https:// 기본, http:// 선택. 전체 HTTP(S) 주소를 입력하면 프로토콜과 나머지 주소를 분리. 클립보드 붙여넣기 버튼으로 문장 또는 Markdown 링크에서 첫 웹 주소 추출. 권한 거부 시 직접 붙여넣기 안내. 기존 상대경로·mailto·tel 링크 보존.
- 원문 창: 줄 번호 On/Off, 최초 On, mde.source.ln으로 브라우저별 기억.
- 원문·아웃라인·렌더링 우측 상단 복사: 원문은 Markdown, 아웃라인은 표시된 구조 텍스트(접힌 내용 제외), 렌더링은 표시된 일반 텍스트. 복사됨 1.5초 표시. Clipboard API 실패 시 호환 복사 경로.
- 렌더링 링크: TOAST UI linkAttributes로 target=_blank, rel=noopener. 편집 포커스 없는 상태 일반 클릭은 새 탭. 이미 편집 중이면 일반 클릭/Shift 선택은 편집에 남기고 Ctrl/Cmd+클릭으로 열기. 링크 드래그 선택은 탐색하지 않음.
