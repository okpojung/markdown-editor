# 1.0.6 한 줄 반응형 편집 도구

- 공통 순서: 파일, 보기, 제목, 텍스트 강조, 글머리, 삽입. 별도 문서 닫기 버튼은 제거하고 파일 메뉴의 닫기는 유지합니다.
- 보기 메뉴: 목차, MD, 아웃라인, 렌더링, 분할. 작은 화면에서는 언어와 설정도 보기 메뉴 안에서 접근합니다.
- 넓은 화면의 텍스트 강조/글머리/삽입 버튼은 직접 표시하고, 1000px 이하에서는 각 그룹 아이콘의 하위 메뉴로 표시합니다. 문서 상태는 하단에 표시합니다.
- 분할 왼쪽 창: 기본 MD, MD/아웃라인 선택 및 왼쪽 창 닫기. 닫으면 렌더링 창이 유지되며 문서를 닫거나 삭제하지 않습니다.
- 글머리/번호/체크박스는 빈 줄에서 먼저 눌러 입력을 시작할 수 있습니다. 같은 빈 항목에서 다시 누르면 취소됩니다. 중첩 빈 항목도 문단으로 해제하며 주변 내용은 보존합니다.
- 메뉴 키보드: 아래 화살표로 열기, 위/아래/Home/End 이동, Escape 닫기. 닫힌 메뉴에 포커스를 남기지 않습니다.
- MD/완전 오프라인 HTML/암호화 HTML, Windows/macOS/Linux 앱은 동일한 공통 원본을 사용합니다. EMM 연동 사본과 운영 배포는 EMM 담당 세션에서 별도로 통합합니다.

## 검증 계약

`tests/toolbar.browser.js`는 격리 자료에서만 실행되며 4언어의 정확한 152개 사례를 검사합니다. 설치 앱 smoke 및 릴리스 검증기는 누락·실패·중복·다른 사례를 거부합니다. 기존 표/코드 34개, 표 격자 52개, 분할 동기화 60개, 암호화 24개 계약도 유지합니다.

브라우저 반응형 검증은 한국어/영어/일본어/중국어, 320/360/390/520/768/1000/1024/1440px에서 한 줄 배치와 가로 넘침을 별도로 확인합니다. 운영 배포 완료 여부는 릴리스와 실제 운영 바이트/화면 증거로 별도 확인해야 합니다.
