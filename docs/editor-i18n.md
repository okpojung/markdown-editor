# 편집기 4언어와 홈페이지 언어 연결

## 사용
- 홈페이지에서 언어를 고른 뒤 편집기 열기를 누르면 같은 언어의 편집기가 새 탭에서 열립니다.
- 편집기 설정 → 편집기 언어에서 한국어·영어·일본어·중국어(간체)를 바꿀 수 있습니다. 상단 국기 메뉴도 같은 설정에 연결됩니다.
- URL lang/locale → 기존 EMM 첨부 모드의 선택적 언어 상속 → 편집기 선호 mde.lang → 지원되는 브라우저 언어 → 한국어 순입니다. ko-KR/en-US/ja-JP/zh-CN/zh-Hans를 정규화합니다.
- UI 203키 및 TOAST 기본 UI 48키를 각 4언어로 제공합니다. 사용자 문서·코드·파일명은 번역하지 않습니다.

## 보존되는 상태
- 페이지를 새로고침하지 않고 언어를 바꿉니다. 원문·렌더링의 대기 중 입력, 문서, 미저장 상태, 원문 선택/실행 취소, 테마와 줄번호를 보존합니다.
- 렌더링 편집기 내부 실행 취소 기록은 재생성으로 초기화됩니다. 설정 화면에 이를 안내합니다.
- 온라인/오프라인 저장 파일에도 언어 설정과 사전을 포함합니다.

## 검증 범위
- 합성 문서의 4언어 설정, 4가지 보기, 빠른 원문/초점이 있는 렌더링 입력 후 언어 전환, 테마·줄번호·번역 선택지, .md/온라인/오프라인 저장과 오프라인 파일 재열기. 실제 파일시스템에는 쓰지 않는 저장 인터페이스 대역을 사용했습니다.
- 390px 설정창의 언어 컨트롤과 자체 가로 넘침 없음. 기존 편집기 전체 모바일 레이아웃 개선은 별도 범위입니다.
- 실제 EMM 운영 데이터에 대한 읽기/쓰기·사본 교체·앱 배포는 수행하지 않습니다. 기존 첨부 메시지의 origin/source/key 검사와 저장 규약은 보존합니다.
