# 아웃라인 편집 시험 절차

## 준비

1. `index.html`을 더블클릭해 Chrome이나 Edge로 엽니다. 인터넷 연결이 필요합니다.
2. 오른쪽 위 **열기** → 같은 폴더의 `outline-test.md`를 엽니다.
3. 위쪽 **아웃라인** 버튼을 누릅니다.
4. 각 단계가 끝나면 **마크다운**이나 **분할**을 눌러 원문을 확인한 뒤 다시 **아웃라인**으로 돌아옵니다. 제목 변화는 왼쪽 목차에서도 바로 보입니다.
5. 처음부터 다시 하려면 **열기**로 `outline-test.md`를 다시 엽니다.

## 조작 규칙

| 키 / 동작 | 선택 상태 (클릭만 함) | 입력 상태 (더블클릭 또는 F2) |
|---|---|---|
| Enter | 아래에 같은 종류 노드 추가 후 입력 상태 | 입력 확정 후 아래에 노드 추가 |
| Tab / Shift+Tab | 들여쓰기 / 내어쓰기 (하위 함께) | 확정 후 들여쓰기 / 내어쓰기, 입력 상태 유지 |
| Shift+Enter | - | 줄바꿈 (문단은 실제 줄바꿈, 제목·목록은 `<br>`) |
| Esc | - | 취소. 방금 Enter로 만든 노드라면 노드 자체를 지움 |
| Alt+↑ / Alt+↓ | 같은 단계 안에서 위/아래로 이동 | - |
| ↑ / ↓ | 위/아래 노드 선택 | - |
| ← / → | 접기 (이미 접혀 있으면 부모 선택) / 펼치기 | - |
| Delete | 노드 삭제 (하위 함께) | - |
| Ctrl+Z / Ctrl+Y | 아웃라인 작업 되돌리기 / 다시 실행 | - |
| 끌어서 놓기 | 행 위쪽 30% = 앞, 아래쪽 30% = 뒤, 가운데 = 안(마지막 하위) | - |

끌 때 표시: 주황 윗줄 = 앞, 주황 밑줄 = 뒤, 점선 상자 = 안. 표시가 안 나오면 놓을 수 없는 자리입니다(예: 제목을 목록 안으로).

## 시험 항목

| 번호 | 조작 | 기대 결과 (원문) |
|---|---|---|
| 1 | **A-1 준비** 클릭 → Enter → `A-1.5 추가` 입력 → Enter → (새 노드가 또 생김) → Esc | `## A-1.5 추가`가 `- 할 일 3` 다음, `## A-2 실행` 앞에 생김. `새 노드`는 남지 않음 |
| 2 | **A-1.5 추가** 클릭 → F2 → Tab | `### A-1.5 추가`(A-1 준비의 하위). 입력 칸이 계속 열려 있음 |
| 3 | 이어서 Shift+Tab → Esc | `## A-1.5 추가`로 복귀 |
| 4 | **A-2 실행** 클릭 → Tab | `### A-2 실행`, 하위 `#### A-2-1 세부 실행`도 함께 한 단계 내려감 |
| 5 | 이어서 Shift+Tab | 둘 다 원래 단계로 복귀 |
| 6 | **할 일 2** 클릭 → Tab | `  - 할 일 2`(2칸), `    - 세부 2-1`, `    - 세부 2-2`(4칸) |
| 7 | 이어서 Shift+Tab | 들여쓰기 원래대로 |
| 8 | **세부 2-1** 클릭 → Enter → `세부 2-1b` 입력 → 빈 곳 클릭 | `  - 세부 2-1b`가 세부 2-1 바로 아래에 생김 (빈 곳 클릭 = 저장) |
| 9 | **A-1 준비** 클릭 → Alt+↓ | A-1 준비가 목록과 함께 A-1.5 추가 아래로 이동 |
| 10 | 이어서 Alt+↑ | 원위치 |
| 11 | **A-3 정리**를 끌어 **프로젝트 B** 행 가운데에 놓기 (점선 상자) | `## A-3 정리`와 표가 `## B-1 조사` 목록 뒤로 이동 (프로젝트 B의 마지막 하위) |
| 12 | **자료 수집**을 끌어 **할 일 3** 행 아래쪽에 놓기 (주황 밑줄) | `- [ ] 자료 수집`이 `- 할 일 3` 바로 다음 줄로 이동 |
| 13 | **할 일 3**을 끌어 **할 일 1** 행 가운데에 놓기 | `  - 할 일 3`이 할 일 1의 하위로 들어감 |
| 14 | **A-2 실행**(제목)을 끌어 **할 일 1**(목록) 위에 올리기 | 표시가 나오지 않고, 놓아도 아무 변화 없음 |
| 15 | **B-1 조사** 클릭 → Delete → Ctrl+Z → Ctrl+Y → Ctrl+Z | 하위 목록과 함께 삭제 → 복구 → 다시 삭제 → 복구 |
| 16 | **A 개요 문단입니다.** 더블클릭 → 끝에서 Shift+Enter → `둘째 줄` 입력 → Enter | 원문에 두 줄짜리 문단 (`A 개요 문단입니다.` / `둘째 줄`)과 그 아래 새 문단 노드 |
| 17 | 한글로 길게 입력하면서 Enter를 바로 누르기 | 글자가 잘리거나 노드가 두 개 생기지 않음 |
| 18 | **분할** 모드로 바꾸기 | 원문과 렌더링 양쪽에 같은 결과. 제목 수와 목록 항목 수가 같음 |

## 알아둘 점

- 되돌리기(Ctrl+Z)는 아웃라인에서 한 작업만 대상입니다. 원문이나 렌더링에서 글을 고치면 아웃라인 되돌리기 기록이 비워집니다.
- EMM의 "Space로 들여쓰기"는 넣지 않았습니다(글 입력과 겹치기 쉬워서). 필요하면 선택 상태에서만 동작하도록 추가할 수 있습니다.
- 표, 코드, 인용, 구분선은 끌어서 옮길 수 있지만 글 수정은 표만 가능합니다(더블클릭 → 표 편집기).
- 이전 버전은 `index_v1.html`로 남아 있습니다.
